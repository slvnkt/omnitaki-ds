# Skeleton

A placeholder that shows **where** content will appear while it loads. It keeps the geometry of the real content — line heights, block sizes, avatar circles — so the layout doesn't jump when data arrives.

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

```tsx
import { Skeleton } from './components/Skeleton'

<div aria-busy="true" aria-label="Loading delivery">
  <Skeleton size="sm" width="40%" />
  <Skeleton shape="block" height={48} />
</div>
```

## Shapes and sizes

| Shape | Use for | Sizes |
|---|---|---|
| `text` | A line of text | `sm` 12 · `md` 16 · `lg` 20 — for Caption, Body 1, Body 2 / Subtitle lines |
| `block` | Charts, images, big numbers, bars | any `width` × `height` (use the real content's height) |
| `circle` | Avatars, icons | `sm` 24 · `md` 32 · `lg` 40 |

## Do's and don'ts

<Rules>
  <Rule kind="do" title="Mirror the content" example={<Stack><Skeleton size="sm" width="40%" /><Skeleton shape="block" height={40} /><Skeleton size="sm" width="60%" /></Stack>}>
    Same number of lines and similar widths as the content that will replace it.
  </Rule>
  <Rule kind="dont" title="One generic spinner block" example={<Stack><Skeleton shape="block" height={120} /></Stack>}>
    A big grey box hides the structure and makes the layout jump on load.
  </Rule>
  <Rule kind="do" title="Vary line widths" example={<Stack><Skeleton width="90%" /><Skeleton width="75%" /><Skeleton width="50%" /></Stack>}>
    Natural, varied widths read as text.
  </Rule>
  <Rule kind="dont" title="Skeleton for instant actions" example={<Stack><Skeleton width={80} shape="block" height={32} /></Stack>}>
    Don't skeleton a button or anything that loads in under ~300 ms — it only flickers.
  </Rule>
</Rules>

## Accessibility

- **Hidden from screen readers.** Every Skeleton is `aria-hidden="true"`.
- **Announce loading on the container:** set `aria-busy="true"` (and an `aria-label`, e.g. "Loading delivery") on the region that is loading; remove it when content arrives.
- **Motion.** Shimmer and pulse stop with `prefers-reduced-motion: reduce` — the skeleton becomes a static shape.
- **Keyboard.** Skeletons never take focus; don't render focusable placeholders.
- **Contrast.** `bg/tertiary` on `bg/primary` is 1.3 : 1 (Light) / 1.5 : 1 (Dark). Skeletons are decorative, so no minimum applies — they only hint at layout.
